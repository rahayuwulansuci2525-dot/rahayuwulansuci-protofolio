Gambaran Project

Project ini merupakan website wisata sederhana yang dibuat menggunakan HTML dan CSS. Website berisi beberapa rekomendasi tempat wisata alam di Kota Ampana seperti Tanjung Api, Pantai Pasir Putih, Pemandian Malotong, dan Tanjung Lawaka. Selain menampilkan informasi wisata, website ini juga memiliki tampilan galeri foto dan lokasi maps untuk memudahkan pengunjung melihat lokasi wisata.

Proses Riset dan Persiapan

Dalam proses pembuatan website ini, saya melakukan beberapa tahap sederhana untuk mengumpulkan informasi dan menentukan tampilan website yang sesuai.

  • Mencari referensi desain website wisata sederhana melalui internet dan media sosial
  • Mengumpulkan beberapa foto wisata alam yang ada di Kota Ampana
  • Menentukan warna website yang sesuai dengan tema wisata alam dan pantai
  • Menyusun struktur halaman seperti home, tentang, wisata, detail wisata, dan galeri
  • Mencoba menampilkan lokasi wisata menggunakan Google Maps embed

Pengembangan Website

Dalam proses pengembangan website, saya mencoba membuat tampilan yang sederhana, rapi, dan mudah digunakan oleh pengunjung.

  • Menggunakan kombinasi warna soft seperti biru muda, putih, dan beige agar sesuai dengan tema wisata alam
  • Membuat tampilan website sederhana dengan layout yang mudah dipahami pengguna
  • Menambahkan navbar untuk memudahkan perpindahan antar section website
  • Membuat galeri foto wisata menggunakan grid layout
  • Menambahkan Google Maps untuk menampilkan lokasi wisata secara langsung

Hasil dan Pembelajaran

Melalui project ini, saya mendapatkan pengalaman dan pemahaman dasar dalam membuat website menggunakan HTML dan CSS.

  • Belajar menyusun struktur halaman website dengan lebih rapi dan teratur
  • Memahami cara membuat tampilan galeri menggunakan grid layout
  • Belajar menggunakan Google Maps embed untuk menampilkan lokasi wisata
  • Menambah pengalaman dalam membuat project website bertema wisata alam
