Gambaran Project

Website DompetKu dibuat sebagai latihan dalam memahami dasar pengembangan website interaktif menggunakan JavaScript. Project ini berfokus pada pengelolaan data pengeluaran harian dengan tampilan dashboard sederhana dan modern. Pengguna dapat menambahkan data pengeluaran, melihat total pengeluaran, mengedit data, menghapus data, serta mencari data pengeluaran berdasarkan nama.

Analisis Kebutuhan

Dalam proses pembuatan website ini, saya melakukan beberapa tahap sederhana untuk menentukan fitur dan tampilan website yang sesuai.

  • Mencari referensi desain dashboard keuangan sederhana melalui internet
  • Mempelajari penggunaan LocalStorage untuk menyimpan data pada browser
  • Menyusun fitur utama seperti tambah data, edit data, hapus data, dan pencarian data

Pengembangan Website

Dalam proses pengembangan website, saya mencoba membuat tampilan dashboard yang sederhana, modern, dan mudah digunakan.

  • Menggunakan HTML untuk membuat struktur halaman website
  • Menggunakan CSS untuk membuat tampilan dashboard yang rapi dan modern
  • Membuat fitur edit, hapus, dan pencarian data pengeluaran
  • Membuat card dashboard untuk menampilkan jumlah data dan total pengeluaran

Hasil dan Pembelajaran

Melalui project ini, saya mendapatkan pengalaman dan pemahaman dasar dalam membuat website interaktif menggunakan JavaScript.

  • Memahami cara menyimpan dan mengambil data menggunakan LocalStorage
  • Belajar membuat fitur CRUD sederhana menggunakan JavaScript
  • Memahami cara mengelola array dan menampilkan data secara dinamis
  • Menambah pengalaman dalam membuat dashboard website sederhana
